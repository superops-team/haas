# Manager HaaS Backend Functional Verification Cases

**English** | [简体中文](CASES.zh-CN.md)

Status: Draft
Change ID: manager-haas-sidecar-spec

These cases are the executable acceptance contract for the default Lite HaaS backend, delegated configuration updates, recovery, and the AIO compatibility path. Offline tests run by default. Real Docker/Codex cases require explicit environment switches and are reported `not_run` when unavailable; they are not silently replaced by mocks. Evidence belongs in the final handoff/PR description, not a committed verification directory.
